FAQ

Frequently asked questions

Is Xeno safe to use?

Yes. Xeno is open source on GitHub and can be audited by the community. Antivirus detections are false positives due to the low-level injection mechanism, not actual threats. Download only from the official GitHub page and links in the README.

Do I need a key to use Xeno?

No. Xeno is completely keyless. No keys, wait timers, or third-party links. Download, run, and you're good to go.

Windows Defender deletes xeno.exe — what to do?

This is a false positive. Add the Xeno folder to Windows Defender exclusions before downloading, then re-download from the official link. Do not disable your antivirus entirely — adding an exclusion is sufficient.

Injection fails after a Roblox update

Roblox has likely updated since your last session. Check for a Xeno update via the auto-updater, fully restart both Roblox and Xeno, then try again.

Is there a mobile version?

Yes, an Android APK Beta is available for Android 8.0+. An iOS version is in development. Use only the official links from the repository.

Where can I find the source code and support?

The source code is available in the GitHub repository. Support and script sharing are in the official Xeno Discord server.
